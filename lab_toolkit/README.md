# 实验工具箱（离线网页版）

**使用方法：双击 `实验工具箱.html`**，会用浏览器（Chrome、Edge、Safari 都可以）打开。不需要安装软件，也不需要联网。所有数据只在本机浏览器里处理，不会上传。这个文件可以拷到实验室电脑上用，也可以发给同组同学。

## 五个工具

| 工具 | 解决什么问题 | 输出 |
|---|---|---|
| **① 统计与作图** | 从 Excel 粘贴数据，自动做正态性和方差齐性检验，再选择合适的方法：单因素方差分析 + Tukey、Welch 方差分析 + Games-Howell，或 Kruskal-Wallis + Dunn | 文献风格的柱状散点图（\* 表示与对照组比较，# 表示与模型组比较），可下载 PNG / SVG；统计结果表；可以改写进论文的「统计方法」和「结果」文字 |
| **② 随机分组 / 盲法** | 按基线体重（和抓力）做分层区组随机，各组基线一致；生成不重复的三位数盲码 | 分组平衡检查表（含方差分析 P 值）、分组总表、盲法记录表。用**随机种子**可以复现结果 |
| **③ CUMS 应激日程** | 按周排出应激方案：同一种应激不连续两天出现；同一天的几种应激类别不同；各种应激出现次数尽量平均 | 日程表（可下载 CSV、可打印） |
| **④ 数据计算** | 糖水偏好、抓力（多次测量求平均值和最大值，并做体重校正）、体重变化曲线、揭盲合并（按盲码补上组别） | 结果表；任意一列可一键送去 ① 做统计作图 |
| **⑤ 悬尾 / 强迫游泳计时** | 打开实验视频，动物不动时按住空格键，自动统计指定时段（默认 120–360 s）内的不动时间、不动段数和潜伏期 | 结果自动保存在浏览器里，可下载 CSV |

## 推荐的数据流程

1. 分组前测基线体重和抓力，用 **②** 随机分组。分组总表交给不参与测量的人保管，测量人员只用盲码。
2. 用 **③** 生成 CUMS 日程，打印后贴在动物房。
3. 照片和视频都用**盲码**命名。DOR / 舌象用 `DOR_batch` 程序测；悬尾、强迫游泳用 **⑤** 计时；糖水偏好和抓力用 **④** 计算。
4. 全部测完后，用 **④ → 揭盲合并** 补上组别，再送去 **①** 做统计和作图。

## 统计结果可靠吗？

统计计算都用 Python 的 scipy、statsmodels、pingouin 做了核对，测试脚本在 `test/test_stats.py`。核对了 60 组随机数据：方差分析、Tukey、Welch 方差分析、Brown-Forsythe、Kruskal-Wallis、Dunn、Shapiro-Wilk 的结果都一致，误差在 1e-6 以下。Games-Howell 在样本极小、方差极不齐（自由度约等于 2）时误差约 5e-5，不影响报告到小数点后 3 位的 P 值。

## 没有做、建议用现成软件的

- **重复测量方差分析或混合模型**（比如每周体重、多时间点的抓力）：请用 SPSS 或 GraphPad Prism。④ 可以画曲线，并把单个时间点送去 ① 做组间比较。
- **旷场轨迹自动追踪**：推荐用免费的 ezTrack 或 ToxTrac。
- **悬尾、强迫游泳自动判读**（AI 识别不动）：需要训练模型（如 DeepLabCut），工作量很大。人工按键计时加盲法，是审稿人普遍接受的方法。
