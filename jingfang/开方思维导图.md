# 怎么开方：流程 → 选法 → 方阵里选方 → 复诊

## 一、看病流程：先走完这几步，再选法
- 说明：每一步都写判据。错题复盘时，按这几步查是哪一步错了。

### 0　问来路：起病几日、传到哪一步、用过什么治法
- 说明：问发过汗、服过退烧药（津已亏，葛根汤比麻黄汤常用）、攻下过（伤胃）、清热过（伤阳）、温补过（易化热）；是否手术后、产后、大病后（津血骤亏）〔伤〕〔金〕。
- 说明：复诊先问上诊方、剂数、实际服药天数、有无外感、西药（尤其激素）变化，再和上诊对比：是病进，还是里邪出表〔skill〕。
- 说明：首诊问既往用过什么方、效果如何；曹老常复用有效的旧方〔skill〕。

### 1　四诊与他觉：扪手、下睑、腹按、下肢四项必查
- 说明：问诊先里后表：寐、情绪；寒热、汗、身、疲劳；头、心、胸；口、饮、咽、鼻、咳；纳、胃；二便；经带〔skill〕。
- 说明：他觉：扪手（凉温热、潮干）、脉、舌、面、下睑（淡白、淡红、半红半白、红鲜、暗红）、腹按（软、满、薄拘、痞硬、压痛）、下肢（干燥、甲错、血络、按肿）。缺这四项时判断可靠性明显下降〔skill〕。
- 说明：病人自诉的寒热，要用扪手、下睑、舌脉校对〔伤〕。

### 2　基础病机三行：表／太阴／阳明，每项写依据
- 说明：阳明每项标虚实：睑淡白、唇舌淡、手凉＝虚热；睑红鲜、舌唇红、面赤＝实热〔skill〕。
- 说明：口干而饮少、喜温是热不实；消水、喜冷饮才是实热〔酸〕。
- 表：表束、表寒、中风、伤营、伤精
  - 说明：表束：怕风、吹风周身不适、头胀头晕、心慌胸闷、颈腰肢体酸痛、行走不稳、鼻塞、面部油腻、肢体不用
  - 说明：表寒：怕冷、手足凉、他觉身凉、下肢凉
  - 说明：中风：易汗、汗后凉或怕风、手潮、盗汗、食汗
  - 说明：伤营：眠差、多梦、入睡难、手足或周身麻木、记忆力差、夜间恐惧、皮损
  - 说明：伤精：肌肉萎缩、羸瘦、遗精、不孕不育
- 太阴：里虚、里寒、水饮、伤血、血少
  - 说明：里虚：纳差、腹胀、嘈杂、便日 1–2 行偏软或稀、饮酒或食凉后便溏
  - 说明：里寒：腹凉、小腹畏寒、食凉胃闷或胃痛
  - 说明：水饮：夜尿、尿频、袜痕、按肿、目下卧蚕、白痰、流涎、带下、反酸、面肿
  - 说明：伤血：下肢血络、经色暗或有血块、刷牙出血、舌紫红、目眶暗黑
  - 说明：血少：下睑淡白、面色萎黄或晄白、经少
- 阳明：里热、里结、里燥、外热、外结、外燥、水热
  - 说明：里热：口干、口苦、口臭、渴而饮多、牙痛、燥热
  - 说明：里结：腹满膨隆、腹硬满、大便 2 日一行、腹薄拘
  - 说明：里燥：大便干燥难解
  - 说明：外热：自觉发热、手温、皮疹红
  - 说明：外结：皮损突起、火痤血痤、色斑、瘀斑、破溃
  - 说明：外燥：下肢甲错、皮肤干燥、脱屑
  - 说明：水热：尿灼热、烧心

### 3　约分：先表，再太阴，以太阴校阳明
- 说明：表上后一层包前一层（表寒 → 中风 → 伤营 → 伤精），见伤营就治伤营；太阴后一层由前一层引起（溢饮 ← 淡饮 ← 胃虚 ← 里寒），治最前一层〔skill〕。
- 说明：热从哪里来就从哪里解：表寒郁热用辛温发散；津血虚寒以虚为主的虚热用甘温补益；以寒为主的虚热用辛热；水饮郁而化火用酸温；实火才用阳明四法〔伤〕〔厥〕。
- 说明：表证三层面：二便、经带先出问题 → 外证，纯治里，不可攻表；对外邪敏感（恶风、受凉加重、无汗身痛）→ 有表邪，发表为主；两样都没有而表证明显 → 里邪冲逆，治里为主、兼顾表〔skill〕。
- 说明：主诉看"主诉"一栏；lmp 和月经一栏是例行记录，不当第一层〔skill〕。

### 4　复合病机：六病；半病门槛；少阳还是厥阴
- 说明：三观定位：表里（病位）、正邪（胃气是病传关口）、津液〔skill〕。
- 说明：中风：以表（上焦）为所急所苦，并有汗出、营卫不和〔伤〕。
- 说明：半病门槛：有胃虚，又有两个方向相反、要分头对治的需要（滋胃津又化饮、补虚又去实、要解表而人虚）〔skill〕。
- 说明：以上焦表位火证为苦、1–3 日即传 → 少阳；以下焦里位水证血证为苦、缠绵 → 厥阴。厥阴要有表证；口苦而胃和不先想小柴胡汤〔skill〕。
- 说明：真厥阴（手肘以上也凉、肤冷、躁无暂安、脉微欲绝）要回阳，禁解表；被水火气血阻碍而厥的是类厥阴〔伤〕〔厥〕。

### 5　四证：第一层属水火气血哪一证
- 说明：定第一层、兼证和水火比例。辨出某一经后，一定要落实到水火气血上才算瞄准：同是太阴，水证用肾著汤，血证用黄芪建中汤〔厥〕。
- 说明：咽中痰滞、苔白腻、便偏稀而又口干脉滑，是饮为本、热为标，先化痰饮〔skill〕。
- 说明：胸闷气短、胃胀等气饮层为所急所苦时，按肿退到第二层〔skill〕。

### 6　关卡：阳旦排除、关键药准入、黄芪门槛
- 说明：阳旦排除：火证为苦、里阳盛、外证、真厥阴、表上红肿热盛、手足温热便干渴饮多〔skill〕。
- 说明：关键药准入〔skill〕：
- 说明：麻黄：表之津液实（有汗也可）；以血虚为苦、睑红干枯、胃虚而表上有水不用。
- 说明：石膏：阳明里实热基础；里虚寒易动不用。
- 说明：柴胡：三焦不利、上焦郁火；水结重、水寒为主、真阴虚而火为苦不用。
- 说明：前胡：虚人之表、水火夹杂、胃虚。
- 说明：桂枝：表寒、营卫不和；外证、火证、里阳盛不用。
- 说明：黄芪：有表证或水湿；实火重时不配桂枝。
- 说明：人参：有里证或胃虚。芍药：津血虚、虚热、利小便；下后表寒入里、胃气弱、表寒重去芍。
- 说明：茯苓：下焦饮停；外证、火证有水、胃津虚之水不用。
- 说明：附子：有少阴证。饴糖：胃津绝对亏虚；里实里热苔腻有饮不用。栀子：火兼虚水表；旧微溏不用。
- 说明：黄芪门槛：下肢按肿＋太阴中风底子（疲劳、乏力、易汗、恶风、睑白之一）；每诊重过〔skill〕。
- 说明：里急先救里〔伤〕。

### 7　定法三刀：二旦 → 表药 → 四证内的法
- 说明：第一刀定阴阳方向，第二刀用表药定病位，第三刀在水火气血里定具体的法。每一刀都写判据，逐一写邻法为什么不用〔skill〕。

### 8　定方：进方阵 → 选行 → 选列 → 核格
- 说明：进方阵（按复合病机、来路）→ 选行（表证性质＋里证组合定基础方）→ 选列（水火气血哪一个是第一层）→ 核格（方眼在不在、有没有反指征，不合就按分界移格）。
- 说明：落到一张现成古方，原方原量，不临时堆药〔伤〕。
- 说明：剂量 1 两≈6g，按原方原量写。减量只在资料写明的场合：合方减半为主〔厥〕；方太猛、太苦或太贵（厚朴七物汤、黄连阿胶汤）〔金〕〔伤〕；看病情（温经汤治痛经多半量、治不孕多全量）〔伤〕；首次试探（橘皮汤先半量）〔伤〕；两味药的小方用全量〔金〕；小儿酌减。

### 9　邻方对照：方眼在否、反指征、管不管第一层
- 说明：前 3–4 张候选方各写一行：方眼在不在、反指征有没有、管不管得到所急所苦和第一层。有反指征或管不到第一层的方不能排第一〔skill〕。
- 说明：几张都说得通时，首诊先选更轻、更窄、偏表或偏中焦祛邪的那张，补益养血留给复诊〔skill〕。
- 说明：再写 1–2 张备选（换方条件、分歧在哪一刀），和 1–2 个能推翻判断的追问，优先问他觉和来路〔skill〕。

### 10　排方与复诊：依病传排方；守还是转
- 说明：一诊可开 2–7 张方，按顺序服或交替服：阳病两三日一传，2–2 交替；阴病四至六日一传，4–4 或 5–5 交替。交替服的两张方方向相反，不能合成一方〔厥〕〔痹〕。
- 说明：常见顺序：先纠虚后攻实；先发表再清降；清火之后虚寒显，用前胡法收尾；温补之后热显，转清法；温里之后适时解表〔厥〕〔痹〕。

## 二、选法：进哪个方阵：按复合病机或来路；再用三刀定法
- 说明：先用复合病机或来路决定进哪个方阵，再用定法三刀核对：二旦定方向，表药定病位，四证定具体的法。

### 按复合病机进方阵：九种复合病机对应九个方阵
- 少阳中风、厥阴中风：→ 方阵一：厥阴中风三法
  - 说明：少阳中风、厥阴中风 → 方阵一：厥阴中风三法
- 太阴中风、血痹（在表）：→ 方阵二：太阴中风·辛温血痹（黄芪族）
  - 说明：太阴中风、血痹（在表） → 方阵二：太阴中风·辛温血痹（黄芪族）
- 阳明实火：→ 方阵三：阳明四法
  - 说明：阳明实火 → 方阵三：阳明四法
- 类厥阴本病：→ 方阵四：泻心·乌梅
  - 说明：类厥阴本病 → 方阵四：泻心·乌梅
- 太阳表证：→ 方阵五：太阳
  - 说明：太阳表证 → 方阵五：太阳
- 阳明表热、阳明血痹：→ 方阵六：辛寒血痹·表解肌
  - 说明：阳明表热、阳明血痹 → 方阵六：辛寒血痹·表解肌
- 太阴里证（虚寒、水饮、胃气）：→ 方阵七：太阴温之四法·水饮
  - 说明：太阴里证（虚寒、水饮、胃气） → 方阵七：太阴温之四法·水饮
- 太阴伤血、虚劳：→ 方阵八：建中·血
  - 说明：太阴伤血、虚劳 → 方阵八：建中·血
- 少阴：→ 方阵九：少阴
  - 说明：少阴 → 方阵九：少阴
- 真厥阴：→ 四逆辈
  - 说明：真厥阴 → 四逆辈：要回阳，禁解表〔伤〕。

### 按来路直接定位：来路决定去路
- 说明：来路决定去路：从太阴传入的走寒疝、虚劳方向（方阵二、方阵八）；从阳明传入的走痈脓、肠痈、阴阳毒方向（方阵六）。〔痹〕〔厥〕
- 太阳表不解＋胃虚：→ 少阳中风：柴胡桂枝汤
  - 说明：太阳表不解＋胃虚 → 少阳中风：柴胡桂枝汤〔厥〕
- 上一条再加胃寒（里寒）：→ 厥阴中风：前胡桂枝汤（竹叶前胡汤）
  - 说明：上一条再加胃寒（里寒） → 厥阴中风：前胡桂枝汤（竹叶前胡汤）〔厥〕
- 再虚热转实，里阳盛去桂：→ 前胡升麻地黄汤
  - 说明：再虚热转实，里阳盛去桂 → 前胡升麻地黄汤〔厥〕
- 太阴里阳虚＋寒饮：→ 前胡苓桂术甘汤
  - 说明：太阴里阳虚＋寒饮 → 前胡苓桂术甘汤〔厥〕
- 少阴卫阳虚＋里热：→ 前胡桂枝附子汤
  - 说明：少阴卫阳虚＋里热 → 前胡桂枝附子汤〔厥〕
- 太阴虚热转实（黄汗层）：→ 芪芍桂酒汤
  - 说明：太阴虚热转实（黄汗层） → 芪芍桂酒汤〔厥〕
- 阳明虚实夹杂（大病后劳复）：→ 枳实栀子豉汤
  - 说明：阳明虚实夹杂（大病后劳复） → 枳实栀子豉汤〔厥〕

### 定法三刀：二旦 → 表药 → 四证内的法
- 第一刀：二旦：阳旦、阴旦，还是二旦合
  - 阳旦：气的温煦不足而见寒：桂枝、黄芪
    - 说明：阳旦层级：桂枝甘草 → 桂枝汤 → 建中 → 青龙 → 续命 → 石散。
    - 说明：太阴中风四层（后层包前层）：邪风虚热（桂枝汤）→ 水饮血痹（桂枝加黄芪汤）→ 邪风血病（黄芪桂枝五物汤）→ 风水（防己黄芪汤）、黄汗（芪芍桂酒汤）〔skill〕。
  - 阴旦：血的濡养不足而见热：柴胡、黄芩、芍药
    - 说明：扶阴解表、从阴面解，祖方黄芩加半夏生姜汤。里热津血不足的表证见肢痛就上桂枝、黄芪，是零分错误〔skill〕。
  - 二旦合：寒、热同为所苦
    - 说明：柴胡桂枝汤（两方各取半量）、竹叶前胡汤。一直温则濡养不足，一直滋则温煦不足：阴旦攻下之后多转阳旦〔skill〕〔厥〕。
  - 阳旦排除：见这些就不用桂枝、黄芪打底
    - 说明：火证为苦、里阳盛、外证、真厥阴、表上红肿热盛、手足温热便干渴饮多。排除阳旦后，只在阴旦、解肌、泻心、二旦合里找〔skill〕。
- 第二刀：表药定病位：麻黄、石膏葛根、柴胡、桂枝、黄芪、前胡
  - 麻黄 → 太阳：表之津液实（有汗也可）
    - 说明：不用：以血虚为苦、睑红干枯、胃虚而表上有水。实则麻黄：睑红鲜、周身疼重、腹硬满、脉浮有力〔skill〕。
  - 石膏、葛根、升麻 → 阳明表热：存津液而发汗（解肌）
    - 说明：石膏要有阳明里实热基础，里虚寒易动不用。葛根虚实兼清、偏津亏〔skill〕。
  - 柴胡 → 少阳：三焦不利、上焦郁火
    - 说明：不用：水结重、水寒为主、真阴虚而火为苦。口苦而胃和（纳可、不呕、无胃胀反酸便稀）不先想小柴胡汤〔skill〕。
  - 桂枝 → 少阴：表寒、营卫不和
    - 说明：不用：外证、火证、里阳盛。桂枝汤类的方在方阵五（中风有汗）和方阵八（建中、营血虚）〔skill〕。
  - 黄芪 → 太阴：太阴病之麻黄：须有表证或水湿
    - 说明：虚则黄芪：睑淡白、面萎黄、腹软、甲错、经少。实火重时不配桂枝。黄芪配阴旦，要同时有卫气在表不温不固和津血在里不润不降〔skill〕。
  - 前胡 → 类厥阴：虚人之表、水火夹杂、胃虚
    - 说明：前胡＝不那么温热的黄芪，水药兼补〔skill〕。
- 第三刀：四证内的法：水、火、气、血各有其法
  - 火：实火：七行多数落实火 → 阳明四法
    - 说明：实火、阴火七行（逐行比，多数行落哪边按哪边）〔skill〕：
    - 说明：口渴：实火口燥喜冷饮｜阴火虽渴而喜热饮，或渴饮不一
    - 说明：大便：实火腹满便燥｜阴火虽腹满便秘而便软或无力
    - 说明：寒热：实火恶热不恶寒｜阴火虽恶热常伴恶寒
    - 说明：舌：实火燥、红鲜｜阴火淡、嫩、滑
    - 说明：下睑：实火红鲜｜阴火淡白或淡红
    - 说明：面：实火红赤｜阴火晦暗、萎黄、苍白
    - 说明：脉：实火实｜阴火虚
    - 说明：阳明四法：苦寒（里热燔灼、不兼表虚水）；辛寒（热兼表、冲上焦表位）；咸寒（燥结、血分、水分）；酸寒（火为所苦而兼虚兼水兼表，旧微溏不可）。邻法：酸寒泻实兼顾虚，甘寒治虚兼清热。
  - 火：阴火：甘、酸、咸、石，各配温或寒
